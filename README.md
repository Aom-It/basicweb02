## ✨ ฟีเจอร์หลัก (Features)

- **Clean & Modern UI:** ออกแบบหน้าเว็บให้เรียบง่าย อ่านสบายตา
- **Responsive Design:** จัดวาง Layout ให้สวยงามทั้งบนคอมพิวเตอร์และมือถือ
- **Well-Structured Code:** แยกส่วนโครงสร้าง (HTML) และสไตล์ (CSS) อย่างเป็นระเบียบ

## 📂 โครงสร้างไฟล์ในโปรเจกต์ (Project Structure)

```text
├── css/                 # เก็บไฟล์ Style Sheet สำหรับตกแต่งหน้าเว็บ
├── images/              # เก็บไฟล์รูปภาพและไอคอนที่ใช้ในเว็บไซต์
├── index.html           # หน้าหลักของเว็บไซต์ (เวอร์ชันล่าสุด)
├── Index Original.html  # หน้าหลักเวอร์ชันต้นฉบับก่อนปรับปรุง
└── test01-03.html       # ไฟล์สำหรับทดสอบฟีเจอร์และ Layout ระหว่างพัฒนา
